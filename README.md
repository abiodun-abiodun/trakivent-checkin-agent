# TRAKIVENT

**Smart Event Operations Platform**

Developed by **Manspace Technologies**

---

## Overview

TRAKIVENT is a modern event operations platform designed to simplify guest registration, digital invitations, QR code check-in, attendance monitoring and event analytics.

The platform is being developed as a scalable SaaS solution capable of supporting multiple events, organizations, venues and check-in stations simultaneously.

This repository currently contains the **TRAKIVENT Check-in Agent**, the first operational component of the platform.

---

## Current Module

### TRAKIVENT Check-in Agent

A browser-based QR Code check-in application that enables event staff to verify guest attendance quickly using:

- Device Camera QR Scanner
- USB Barcode / QR Scanner
- Manual QR Token Entry
